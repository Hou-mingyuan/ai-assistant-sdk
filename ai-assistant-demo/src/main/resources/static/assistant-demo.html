Demo 页面正文

本页用于演示 AI Assistant SDK 在纯 HTML 页面中的集成方式：加载发布构建生成的 ai-assistant-wc.umd.cjs，然后声明 <ai-assistant> 元素即可。 Web Component 自带 Vue 运行时，不要求宿主页面安装 Vue。

项目中还包含仅使用 fetch 调用 REST 的 index.html，用于独立验证同步 Chat 与健康接口。 完整的 Vue 插件、表单填充与管理面板体验请使用仓库中的 Playground。

后端仍为 Spring Boot Starter，默认上下文路径为 /ai-assistant。 零密钥时使用明确标识的确定性 Demo Provider；真实模型模式必须通过环境变量注入密钥，不能把密钥写进此页面。
